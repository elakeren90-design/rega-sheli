# רגע שלי

יומן אישי קטן לאייפון: משפט אחד או הקלטה קצרה, גם ביום עמוס.

## כתובת האפליקציה

https://elakeren90-design.github.io/rega-sheli/

## לפתוח באייפון (פעם אחת)

1. **לפתוח את הכתובת בספארי.**
2. **להוסיף למסך הבית:** שלוש הנקודות ליד שורת הכתובת ← שיתוף ← הוספה למסך הבית. להשאיר דלוקה את האפשרות לפתוח כאפליקציה.
3. **לפתוח רק מהאייקון.** בהקלטה הראשונה לאשר מיקרופון.

## חשוב לדעת

1. **הרגעים נשמרים רק באייפון, בתוך האייקון.** הם לא עולים לשום מקום. מה שנכתב בספארי עצמו לא יופיע באייקון.
2. **הקוד כאן ציבורי, הרגעים לא.** המאגר הזה מכיל רק את האפליקציה, בלי שום תוכן אישי.
3. **גיבוי מדי פעם:** הרגעים שלי ← גיבוי ← ליצור קובץ גיבוי ← לשמור את הקובץ.
4. **הכתובת צריכה להישאר קבועה.** כתובת אחרת מתחילה יומן ריק, ולכן לפני מעבר: קודם גיבוי ואז שחזור.

## עדכון גרסה

1. **להעלות את מספר הגרסה** בקובץ sw.js (מ־v1 ל־v2 וכן הלאה).
2. **לשמור את השינויים בענף הראשי** של המאגר. האתר מתעדכן לבד תוך כמה דקות.
3. **הגרסה החדשה מופיעה** בפעם השנייה שפותחים את האפליקציה.

## מה יש בתיקייה

1. **index.html ו־styles.css:** המסכים והעיצוב.
2. **js:** שמירה במכשיר, הקלטה, גיבוי והשאלות היומיות.
3. **sw.js ו־manifest.webmanifest:** אפליקציה למסך הבית ופתיחה בלי אינטרנט.
4. **fonts ו־icons:** הגופנים רוביק ופלייפן (רישיון פתוח) והאייקון.
